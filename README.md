# Bespoke Dua API

## Setup

1. Copy `appsettings.Example.json` to `appsettings.Development.json` for local work, and to `appsettings.json` if you need a non-Development environment.
2. Replace the placeholders in those local files. Do not put real keys in `appsettings.Example.json`.

`appsettings.json` and `appsettings.Development.json` are gitignored so local keys are never committed. `appsettings.Example.json` is the template that stays in the repo.
